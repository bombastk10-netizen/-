# ابتكارات الحلا — منيو الحلويات

موقع عربي متجاوب باستخدام HTML وCSS وJavaScript، جاهز للنشر على GitHub Pages دون تثبيت أو بناء.

## الملفات
- index.html: الصفحة الرئيسية.
- css/style.css: الألوان والخطوط والتنسيق.
- js/data.js: أسماء الأصناف والأسعار والأوصاف والصور.
- js/app.js: التفاعل ومقدمة الفيديو التلقائية لمدة ثلاث ثوانٍ.
- assets/: الصور والشعار الشفاف والخطوط والفيديو.

## رفع الموقع
1. فك ضغط الملف على جهازك.
2. في GitHub أنشئ مستودعًا جديدًا (New repository)، مثل ibtikarat-menu، واختر Public.
3. افتح المستودع واختر Add file ثم Upload files (أو uploading an existing file للمستودع الفارغ).
4. ارفع الملفات والمجلدات الموجودة داخل الملف المضغوط. يجب أن يكون index.html مباشرة في جذر المستودع، مع مجلدات assets وcss وjs بجانبه. لا ترفع ملف ZIP نفسه.
5. اضغط Commit changes.
6. من Settings ثم Pages، اختر Deploy from a branch.
7. اختر main والمجلد /(root)، ثم Save.
8. انتظر اكتمال النشر، ثم افتح الرابط الذي يعرضه GitHub في صفحة Pages.

## التعديل
عدّل js/data.js لتغيير الأصناف والأسعار. لتغيير صورة، ضع الملف في assets وحدّث مسار image للصنف. استخدم مسارات نسبية حتى يعمل الموقع داخل مسار المستودع.

## ملاحظات
- المنيو للعرض فقط ولا يحتوي على سلة أو نظام طلبات.
- الصور الحالية توضيحية، وبعض الأصناف مكررة ضمن الأكثر طلبًا كما في الكود الأصلي.
- المقدمة تعمل تلقائيًا في المتصفحات التي تسمح بالفيديو الصامت، وتُتجاوز عند تفعيل تقليل الحركة أو تعذّر التشغيل.
- الملفات مستقلة عن استضافة Sites. لا تحتوي الحزمة على بيانات حساب أو مفاتيح وصول.
- الخط المستخدم Tajawal، من Google Fonts. الصور من Unsplash كما في المنيو، والشعار مقدم من صاحب المشروع.
